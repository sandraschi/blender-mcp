# Blender MCP Bridge Addon

Optional Blender addon for **live GUI sessions** (watch the agent build in the viewport).

Most users do **not** need this — headless Blender works without it.

## Download

| Source | Link |
|--------|------|
| **GitHub Releases** (recommended) | [blender_bridge_addon.py](https://github.com/sandraschi/blender-mcp/releases/latest/download/blender_bridge_addon.py) |
| **This repo** | [blender_bridge_addon.py](blender_bridge_addon.py) |

## Install in Blender

1. **Edit → Preferences → Add-ons → Install**
2. Select `blender_bridge_addon.py`
3. Enable **Blender MCP Bridge**
4. **Properties → Scene → Blender MCP Bridge → Start Bridge**

Full walkthrough: [INSTALL.md](../INSTALL.md#optional-live-blender-viewport-bridge-addon)
